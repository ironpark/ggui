# Tabler

Curated 17-icon outline subset from [tabler/tabler-icons](https://github.com/tabler/tabler-icons),
pinned to `55f87a73f45cf1d9eaf16d7da705065483a9e4f9`. SVG files are copied unchanged from `icons/outline`.
See [LICENSE](LICENSE) for the upstream MIT license.

Use `tabler.Set()` for semantic placeholders or `tabler.Icon("search")`
for a named asset. All shared roles are mapped; names follow upstream.

Only this subset is bundled. Add upstream SVGs under `svg/` to extend it;
all files in that directory are embedded in the binary when imported.
