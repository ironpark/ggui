# Noto Color Emoji

Optional offline color emoji font for ggui, including WebAssembly builds.
Import this package and call `notoemoji.Enable()` before creating the app.
The full font adds about 11 MB to the uncompressed binary; applications using
system fonts or their own emoji font do not import or embed this package.

Source: https://github.com/googlefonts/noto-emoji/tree/06121655d0e82f9cae6e7ba6feed4fa6fdbfc2a4
